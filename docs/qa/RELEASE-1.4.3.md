# VolleyLive 1.4.3 (versionCode 19) – fixes for the 1.4.2 QA findings

Core principle: once the winning rally exists the match is final everywhere. Writable afterwards: a credit on one
of the last 3 rallies, the POTM, the captain verdict / admin fields (and server stamps). Everything else is frozen
(`FINISHED_MATCH_FROZEN`, `src/core/matchGuards.ts`; per-backend table in KNOWN-GAPS "1.4.3 – a finished match is final").
